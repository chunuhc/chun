TKBGO 網頁設計｜2020/4~2022/6

  • 主要負責官網子網頁介面設計及切版，也涵蓋行銷素材、平面文宣等設計、插畫設計、維護更新官網。
  • 曾參與過公司課程平台app功能更新的介面設計。
  • 擁有超過六年的網頁與視覺設計經驗，以及十年以上的工作歷練，能結合行銷需求與設計美感，完成多樣化的數位素材與活動頁面設計。除了視覺設計，也熟悉 HTML、CSS 與 JavaScript，能獨立完成切版及基礎互動效果。
  • 重視團隊合作，善於傾聽並整合不同部門需求，持續以使用者體驗為核心，讓設計更貼近目標客群。
  • 樂於嘗試新工具與技術，並在與行銷、業務及 UX 團隊協作中，不斷優化設計方案，確保成果符合使用者需求與專案目標。

我是一位擅長整合行銷視覺的網頁設計師，能將需求落實為清楚、可用的網頁體驗。工作中注重細節，善於與團隊協作，並持續學習新的設計方法與工具。

累積超過十年的設計經驗，其中六年以上專注於電子商務與活動頁製作，熟悉 Photoshop、Illustrator、InDesign、Adobe XD、Figma 等設計工具，以及 HTML、CSS、JavaScript，能獨立完成切版與基本互動效果。

近期任職於電商平台的產品體驗部門，主要負責行銷活動的整體視覺規劃與製作，包括 Banner、GDN 廣告、社群貼文與 EDM 等素材，並協助活動頁設計與切版，確保品牌形象一致並吸引目標客群。

工作中，我與 UX 設計師及行銷團隊密切合作，規劃活動頁模板、優化視覺流程，根據市場趨勢與使用者回饋持續改善設計，提升使用體驗與點擊轉換率。

過往經驗也涵蓋線上課程平台的官網子頁面設計與維護，包含會員專區、優惠活動頁及小工具介面設計等項目；並有使用 Sourcetree 操作 Git 的經驗，能配合開發流程進行版本管理。

我期許自己能從視覺設計者逐步轉型為具備設計與前端開發能力的跨領域人才，未來希望朝初階前端工程師方向發展，結合設計經驗與程式能力，在設計與開發間發揮橋樑角色，讓產品在視覺與使用體驗上更完整。
